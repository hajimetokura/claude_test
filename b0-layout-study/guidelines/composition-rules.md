# コンポジション（構図）ルール

## B0パネルの基本設計

### パネルスペック
- **サイズ**: 1030mm × 1456mm（B0）
- **マージン（安全領域）**: 各辺 30-40mm
- **有効領域**: 950mm × 1376mm（マージン 40mm の場合）
- **印刷塗り足し**: 各辺 3mm

### 基本グリッド設定

| グリッド種別 | 設定値 | 用途 |
|------------|--------|------|
| 2カラム | 各 455mm + ガター 40mm | 標準的な左右分割 |
| 3カラム | 各 290mm + ガター 40mm | 情報量多めの展示 |
| 4カラム | 各 211mm + ガター 26mm | 細かいグリッド制御 |
| ベースライン | 10mm 間隔 | テキスト整列用 |

## 視線誘導の原則

### Z型パターン（横書き）
```
①──────→②
          │
          ↓
③──────→④
```
最も自然な視線の流れ。タイトル→サブ情報→本文→結論の順に配置。

### F型パターン（情報量多め）
```
①──────→
②────→
③──→
```
見出しを左揃えで縦に並べ、興味のある項目だけ右に読み進める構成。

### 逆N型パターン（縦書き・日本語）
```
      ①
      │
      ↓
②←───
│
↓
      ③
```

## 配置の黄金比

### 上下分割の比率

| 比率 | 上部 | 下部 | 効果 |
|------|------|------|------|
| 1:1 | 728mm | 728mm | 均等・安定感 |
| 2:1 | 970mm | 486mm | 画像主体 |
| 1:2 | 486mm | 970mm | テキスト主体 |
| 黄金比 | 900mm | 556mm | 自然なバランス |
| 1:1:1 | 各 485mm | - | 3段均等 |

## コンテンツ階層

B0パネルの情報は以下の3層で構成する:

### Layer 1: 遠距離（3m+）で読める要素
- メインタイトル
- キービジュアル（1枚）
- ブランドカラー/ロゴ

### Layer 2: 中距離（1-2m）で読める要素
- サブタイトル
- セクション見出し
- 主要な図表
- 大きめのキャプション

### Layer 3: 近距離（0.5m以内）で読める要素
- 本文テキスト
- 詳細データ
- クレジット情報
- QRコード

## パネル間の連続性（複数枚展示時）

### 横並び展示
```
┌────────┐ ┌────────┐ ┌────────┐
│Panel 1 │ │Panel 2 │ │Panel 3 │
│導入     │ │展開     │ │結論     │
│        │→│        │→│        │
└────────┘ └────────┘ └────────┘
```

- パネル間のギャップ: 20-50mm
- 通し番号やカラーコードで連続性を示す
- 視線の高さ（1400mm）にキー情報を揃える

### 色彩計画

| 要素 | 推奨 |
|------|------|
| 背景 | 白 or 極薄グレー（#F5F5F5） |
| メインテキスト | 黒 or ダークグレー（#333333） |
| アクセント | ブランドカラー 1色 |
| 補助色 | グレースケール 2-3段階 |

## チェックリスト

- [ ] 余白は十分か（最低20%）
- [ ] フォントは2種類以内に抑えているか
