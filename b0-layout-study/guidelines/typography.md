# タイポグラフィ ガイドライン

## B0パネルにおける文字サイズ基準

想定閲覧距離に応じた推奨文字サイズ。

### 距離別サイズ表

| 要素 | 近距離 (0.5m) | 中距離 (1-2m) | 遠距離 (3m+) |
|------|-------------|-------------|-------------|
| メインタイトル | 60-80pt | 80-120pt | 120-200pt |
| サブタイトル | 36-48pt | 48-72pt | 72-100pt |
| 本文 | 16-20pt | 20-28pt | 使用しない |
| キャプション | 12-14pt | 14-18pt | 使用しない |
| クレジット | 10-12pt | 12-14pt | 使用しない |

### 展示タイプ別の想定距離

| 展示タイプ | 主な閲覧距離 | 推奨本文サイズ |
|-----------|------------|-------------|
| ギャラリー展示（壁面） | 0.5-1.5m | 18-24pt |
| 展示会ブース | 1-3m | 24-36pt |
| カンファレンスポスター | 0.5-1m | 16-22pt |
| 屋外展示 | 2-5m | 36pt以上 |

## 推奨フォント

### 和文

| 用途 | フォント例 | 特徴 |
|------|----------|------|
| タイトル（モダン） | Noto Sans JP Bold | 視認性高い、クリーン |
| タイトル（建築的） | A1明朝 / 筑紫明朝 | 格調・繊細さ |
| 本文 | Noto Sans JP Regular | 可読性重視 |
| 本文（クラシック） | 游明朝 / ヒラギノ明朝 | 長文の可読性 |
| テクニカル | Source Han Sans | 等幅・技術文書向き |

### 欧文

| 用途 | フォント例 | 特徴 |
|------|----------|------|
| タイトル | Helvetica Neue / Inter | 建築系定番 |
| タイトル（個性的） | Futura / DIN | ジオメトリック |
| 本文 | Helvetica / Arial | 安定した可読性 |
| 数値・データ | DIN / Roboto Mono | 等幅でデータ向き |

## 文字組みの基本ルール

1. **行間（行送り）** — 本文は文字サイズの 1.6-1.8倍
2. **字間（トラッキング）** — タイトルは +20〜+50、本文は 0〜+20
3. **段落間** — 本文1行分以上のアキを入れる
4. **禁則処理** — 句読点や括弧の行頭・行末処理を確認
5. **和欧混植** — 欧文は和文より 1-2pt 小さく、ベースライン調整

## B0固有の注意点

- **最小文字サイズ**: 10pt 未満は使用しない（印刷品質に依存）
- **文字量の目安**: B0縦1枚で日本語 800-1200文字が上限（読み切れる量）
- **色文字**: 背景とのコントラスト比 4.5:1 以上を確保
- **白抜き文字**: 細い書体は避け、Regular以上のウェイトを使用
