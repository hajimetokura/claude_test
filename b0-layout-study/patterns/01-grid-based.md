# Pattern 01: グリッドベース

## 概要

B0パネルを均等なグリッドで分割し、情報を整然と配置するパターン。
技術的な内容や複数の要素を並列に見せたい場合に有効。

## レイアウト構成（B0 縦置き: 1030mm × 1456mm）

```
┌──────────────────────────────────┐
│           ヘッダー領域            │  ← 200mm
│     タイトル / ロゴ / サブタイトル  │
├────────────┬─────────────────────┤
│            │                     │
│  メイン     │   テキスト           │  ← 500mm
│  ビジュアル  │   ブロック           │
│            │                     │
├────────────┼─────────────────────┤
│            │                     │
│  サブ画像1  │   サブ画像2          │  ← 400mm
│            │                     │
├────────────┴─────────────────────┤
│          データ / 図表             │  ← 256mm
│     スペック・数値・グラフなど       │
├──────────────────────────────────┤
│          フッター                  │  ← 100mm
│    クレジット / URL / QR          │
└──────────────────────────────────┘
```

## グリッド設定

- **カラム**: 2列（各 475mm、ガター 80mm）
- **マージン**: 上下左右 40mm
- **ベースライングリッド**: 10mm 間隔

## バリエーション

### A: 2×2 均等分割
```
┌──────────────────────────────────┐
│           タイトル                │
├────────────┬─────────────────────┤
│    A1      │       A2            │
│  (画像)    │     (テキスト)       │
├────────────┼─────────────────────┤
│    A3      │       A4            │
│  (図表)    │     (画像)          │
├────────────┴─────────────────────┤
│           フッター                │
└──────────────────────────────────┘
```

### B: 3カラムグリッド
```
┌──────────────────────────────────┐
│            タイトル               │
├──────────┬──────────┬────────────┤
│   Col 1  │  Col 2   │   Col 3   │
│          │          │           │
│  画像    │  テキスト  │   図表    │
│          │          │           │
├──────────┴──────────┴────────────┤
│           フッター                │
└──────────────────────────────────┘
```

## 適用シーン

- 学会・カンファレンスのポスター発表
- 技術展示会での製品スペック紹介
- 研究成果やデータの比較展示
- 複数プロジェクトの概要一覧

## デザインTips

1. **整列を徹底する** — グリッドからの逸脱は意図的に行う
2. **余白を恐れない** — セル内のパディングを十分に取る（最低 15mm）
3. **視線誘導** — 左上→右下の Z型パターンを意識
4. **情報の階層** — セルのサイズで重要度を表現（大きいセル = 重要）
