# Pattern 06: ダイアグラム中心

## 概要

図解・ダイアグラム・テクニカルドローイングを主役に据えたパターン。
技術的な仕組みや構造、ワークフローを視覚的に説明する展示に最適。
VUILD の CNC加工やロボットアーム技術の紹介に特に有効。

## デザインTips

1. **線の太さ** — B0では主要線 1-2pt、補助線 0.5pt 程度
2. **色分け** — 系統ごとに色を割り当て、凡例で説明
3. **引き出し線** — 45° or 水平/垂直で統一。交差を避ける
4. **スケール感** — 寸法線や人型シルエットでスケールを示す
5. **テキスト量を抑える** — 図で語り、テキストは補足に留める
6. **視線の起点** — 「入力→処理→出力」の流れを左→右 or 上→下で統一
