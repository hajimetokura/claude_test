# Pattern 04: マガジンスタイル

## 概要

雑誌の見開きページのように、画像とテキストを多段組みで配置するパターン。
情報量が多く、複数のトピックを1枚のパネルで伝えたい場合に有効。

## レイアウト構成（B0 縦置き: 1030mm × 1456mm）

### A: 2段組レイアウト
```
┌──────────────────────────────────┐
│  大見出し                         │  ← 120mm
│  リード文（2-3行）                │
├──────────────────────────────────┤
│                                  │
│    メインビジュアル（横長）         │  ← 350mm
│                                  │
├────────────┬─────────────────────┤
│            │                     │
│  本文      │   サブビジュアル      │
│  Col 1     │                     │  ← 350mm
│  （テキスト）│   キャプション       │
│            │                     │
├────────────┼─────────────────────┤
│            │                     │
│  サブ画像   │   本文              │  ← 350mm
│            │   Col 2             │
│  キャプション│  （テキスト）        │
│            │                     │
├────────────┴─────────────────────┤
│  フッター / ページ番号風           │  ← 86mm  (※複数枚パネルの場合)
└──────────────────────────────────┘
```

### B: 非対称グリッド
```
┌──────────────────────────────────┐
│  タイトル                         │
├───────────────────┬──────────────┤
│                   │              │
│    大画像          │  テキスト     │
│   （2/3幅）        │  （1/3幅）   │
│                   │              │
├─────────┬─────────┴──────────────┤
│         │                        │
│ テキスト │      中画像             │
│（1/3幅） │     （2/3幅）           │
│         │                        │
├─────────┼──────────┬─────────────┤
│  小画像  │  小画像   │   テキスト   │
│         │          │  ブロック    │
├─────────┴──────────┴─────────────┤
│  フッター                         │
└──────────────────────────────────┘
```

### C: コラム重視（3段組）
```
┌──────────────────────────────────┐
│  タイトル + リード文               │
├──────────────────────────────────┤
│       メインビジュアル（横長）      │
├──────────┬──────────┬────────────┤
│          │          │           │
│  Topic 1 │ Topic 2  │  Topic 3  │
│  [画像]  │  [画像]   │  [画像]   │
│  [本文]  │  [本文]   │  [本文]   │
│          │          │           │
│          │          │           │
├──────────┴──────────┴────────────┤
│  まとめ / CTA                     │
└──────────────────────────────────┘
```

## 適用シーン

- 複合プロジェクトの紹介（設計・加工・施工を1枚で）
- 会社案内・事業紹介パネル
- 展示会のブース説明パネル
- 複数事例のポートフォリオ展示

## デザインTips

1. **段組みのリズム** — 画像とテキストを交互に配置し、単調さを避ける
2. **見出しの階層** — 大見出し → 中見出し → 本文の 3階層が基本
3. **本文サイズ** — B0で読みやすい本文サイズは 18-24pt（閲覧距離 0.5-1m想定）
4. **カラム幅** — 1行あたり 25-35文字が読みやすい
5. **画像のバリエーション** — 大・中・小の画像を混ぜてリズムを作る
