# Pattern 03: タイムライン

## 概要

プロセスや時系列を視覚的に表現するパターン。設計プロセス、施工過程、
プロジェクトの変遷など「流れ」を見せたい展示に最適。

## レイアウト構成（B0 縦置き: 1030mm × 1456mm）

### A: 垂直タイムライン
```
┌──────────────────────────────────┐
│  タイトル / プロジェクト名         │  ← 150mm
├──────────────────────────────────┤
│  ●─── Phase 1: コンセプト        │
│  │    [画像] [テキスト]           │  ← 250mm
│  │                               │
│  ●─── Phase 2: 設計              │
│  │    [画像] [テキスト]           │  ← 250mm
│  │                               │
│  ●─── Phase 3: 加工              │
│  │    [画像] [テキスト]           │  ← 250mm
│  │                               │
│  ●─── Phase 4: 組立              │
│  │    [画像] [テキスト]           │  ← 250mm
│  │                               │
│  ●─── Phase 5: 完成              │
│       [画像] [テキスト]           │  ← 200mm
├──────────────────────────────────┤
│  フッター                         │  ← 106mm
└──────────────────────────────────┘
```

### B: 蛇行タイムライン
```
┌──────────────────────────────────┐
│  タイトル                         │
├──────────────────────────────────┤
│  Step1 ──→ Step2 ──→ Step3      │
│                          │       │
│  Step6 ←── Step5 ←── Step4      │
│  │                               │
│  Step7 ──→ Step8 ──→ 完成       │
├──────────────────────────────────┤
│  フッター                         │
└──────────────────────────────────┘
```

### C: 水平タイムライン（横置き向け）
```
┌──────────────────────────────────────────────┐
│  タイトル                                     │
├────────┬────────┬────────┬────────┬──────────┤
│        │        │        │        │          │
│ Phase1 │ Phase2 │ Phase3 │ Phase4 │  Phase5  │
│ [画像] │ [画像] │ [画像] │ [画像] │  [画像]  │
│ [説明] │ [説明] │ [説明] │ [説明] │  [説明]  │
│        │        │        │        │          │
├────────┴────────┴────────┴────────┴──────────┤
│  ──────────── 時間軸 ──────────────→          │
├──────────────────────────────────────────────┤
│  まとめ / クレジット                            │
└──────────────────────────────────────────────┘
```

## 適用シーン

- 設計プロセスの展示（スケッチ→3D→施工図→完成）
- ShopBotやCNCの加工工程紹介
- プロジェクトのマイルストーン振り返り
- ビフォー・アフターの比較展示
- VUILD の事業変遷・成長ストーリー

## デザインTips

1. **タイムラインの軸** — 明確な線や矢印で時間の方向を示す
2. **フェーズの差別化** — 色やアイコンで各フェーズを区別
3. **密度のバランス** — 全フェーズを均等にするか、重要フェーズを大きくするか決める
4. **写真の統一感** — 同じアングル・サイズで撮影すると流れが見やすい
5. **ステップ数** — B0縦で 4〜6ステップが適切。多すぎると情報過多になる
