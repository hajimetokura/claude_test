# Pattern 05: ミニマル

## 概要

余白（ホワイトスペース）を積極的に活用し、少ない要素で最大のインパクトを
生み出すパターン。ブランドの世界観やコンセプトを端的に伝える展示に最適。

## レイアウト構成（B0 縦置き: 1030mm × 1456mm）

### A: センター配置
```

│                                  │
│                                  │

│                                  │

│         （パネル中央に集約）        │

│                                  │  ← 余白 400mm

│                                  │
```

## 適用シーン

- ブランド展示・企業コンセプトの発信
- 建築コンセプトの一次提案
- ギャラリーでのアート的展示
- 展示会ブースのキービジュアルパネル
- 「建築の民主化」等のビジョン表現

## デザインTips

1. **余白は最低 40%** — パネル面積の半分近くを空ける勇気が重要
2. **要素は 3つ以内** — 画像1点 + テキスト1ブロック + ロゴが上限
3. **タイポグラフィが主役** — フォント選び・文字組みに細心の注意を払う
4. **色数を絞る** — モノクロ + 1アクセントカラーが基本
5. **素材感** — 用紙の質感（マット/光沢/特殊紙）がデザインの一部になる
6. **近づかせる力** — 遠目でシンプルに見え、近づくと細部が見える二重構造
