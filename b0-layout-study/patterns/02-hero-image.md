# Pattern 02: ヒーローイメージ

## 概要

パネル面積の 50%以上を1枚の大型ビジュアルに割き、建築作品やプロダクトの
インパクトを最大化するパターン。建築展・コンペパネルの定番。

## レイアウト構成（B0 縦置き: 1030mm × 1456mm）

```
┌──────────────────────────────────┐
│                                  │
│                                  │
│                                  │
│         ヒーローイメージ           │  ← 800mm
│        （メインビジュアル）         │
│        パース / 写真 / CG         │
│                                  │
│                                  │
├──────────────────────────────────┤
│  プロジェクト名                    │  ← 120mm
│  サブタイトル / コンセプト文         │
├──────────┬──────────┬────────────┤
│          │          │           │
│  平面図   │  断面図   │  詳細     │  ← 400mm
│          │          │           │
├──────────┴──────────┴────────────┤
│  クレジット / VUILD ロゴ           │  ← 136mm
└──────────────────────────────────┘
```

## バリエーション

### A: 画像上部 + テキスト下部（スタンダード）
上記の基本パターン。最も一般的。

### B: フルブリード画像 + オーバーレイテキスト
```
┌──────────────────────────────────┐
│                                  │
│       フルブリード画像             │
│      （パネル全面に配置）           │
│                                  │
│  ┌─────────────────────────┐    │
│  │  白/半透明ボックス        │    │  ← テキストオーバーレイ
│  │  タイトル + 説明文        │    │
│  └─────────────────────────┘    │
│                                  │
│                                  │
└──────────────────────────────────┘
```

### C: 画像下部配置（逆転レイアウト）
```
┌──────────────────────────────────┐
│  タイトル                        │
│  コンセプト文（長め）              │
│  ダイアグラム / プロセス           │
├──────────────────────────────────┤
│                                  │
│                                  │
│        ヒーローイメージ            │  ← 下部 60%
│                                  │
│                                  │
└──────────────────────────────────┘
```

### D: 左右分割ヒーロー（横置き向け）
```
┌─────────────────┬────────────────┐
│                 │                │
│                 │  タイトル       │
│   ヒーロー       │  説明文        │
│   イメージ       │  図面          │
│                 │  スペック       │
│                 │                │
└─────────────────┴────────────────┘
```

## 適用シーン

- 建築コンペのプレゼンパネル
- 建築作品展（個展・グループ展）
- 施設紹介・竣工写真の展示
- プロダクトデザインの発表

## デザインTips

1. **画像解像度** — B0出力時 150dpi 以上（最低 6100×4400px 程度）
2. **ブリード** — 印刷時の塗り足しを各辺 3mm 確保
3. **テキストの最小サイズ** — B0で 1.5m 距離想定: タイトル 72pt以上、本文 24pt以上
4. **コントラスト** — 画像上のテキストは背景との明暗差を十分に確保
5. **視点の高さ** — 掲示位置（目線 1400-1600mm）を考慮してメインビジュアルを配置
