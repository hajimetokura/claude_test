# 建築設計基準

## このスキルの目的

VUILDの建築設計業務における品質基準・作業手順・チェック項目を定めたマニュアル。
設計部のエージェントが統一された品質で設計業務を遂行するための基準書。

---

## 1. 設計プロセスフロー

```
① 要件整理 → ② コンセプト設計 → ③ 基本設計 → ④ 実施設計 → ⑤ 製作図 → ⑥ 加工データ
     ↓              ↓              ↓             ↓            ↓            ↓
  要件定義書      コンセプト案     基本設計図    実施設計図    製作図      NCデータ
                                                                          ↓
                                                              ⑦ 施工 → ⑧ 完了
```

### 各フェーズの成果物と承認フロー

| フェーズ | 成果物 | 承認者 |
|---|---|---|
| ① 要件整理 | 要件定義書 | Engineering LEAD |
| ② コンセプト設計 | コンセプトスケッチ・方針書 | Engineering LEAD + クライアント |
| ③ 基本設計 | 基本設計図一式 | 設計リード高橋 → Engineering LEAD |
| ④ 実施設計 | 実施設計図一式 | 設計レビュアー山本 → 設計リード高橋 |
| ⑤ 製作図 | 製作図・部材リスト | 設計レビュアー山本 + CNCプログラマー中村 |
| ⑥ 加工データ | NCデータ・加工指示書 | 加工計画担当木村 |

## 3. 設計チェックリスト

### 基本設計チェック
- [ ] 建築面積・延べ面積の法規制限内
- [ ] 用途地域の制限に適合
- [ ] 斜線制限（道路斜線・隣地斜線・北側斜線）の確認
- [ ] 防火・耐火の要件確認
- [ ] バリアフリー法への対応確認
- [ ] 構造方式の妥当性確認
- [ ] 設備スペース（電気・給排水・空調）の確保
- [ ] 動線計画の合理性確認

### 実施設計チェック
- [ ] 全図面の寸法整合性
- [ ] 平面図↔立面図↔断面図の不整合がないか
- [ ] 建具表と図面の整合
- [ ] 仕上表と図面の整合
- [ ] 構造図との整合
- [ ] 設備図との整合
- [ ] 法規適合の最終確認

### 製作図チェック（CNC加工向け）
- [ ] 材料厚さの指定が正しいか
- [ ] ジョイント部の寸法・クリアランスが適切か
- [ ] ビット径に対して隅部のR（角丸）が設定されているか
- [ ] 材料取り（ネスティング）が効率的か
- [ ] 加工原点の指定があるか
- [ ] 部材番号・名称の記載があるか
- [ ] 組立方向・向きの指示があるか

## 4. VUILDの設計思想

### デジタルファブリケーション設計原則
1. **加工機で作れることを前提に設計する** - 手加工前提の設計は避ける
2. **ジョイントで組み立てる** - 接着剤・金物を最小限にし、嵌合で組み立てる
3. **パラメトリックに設計する** - 数値の変更で形状が追従する設計を心がける
4. **材料を無駄にしない** - ネスティング効率80%以上を目標
5. **誰でも組み立てられる** - 専門知識なしで組立可能な設計

### 主要な材料
| 材料 | 厚さ | 主な用途 |
|---|---|---|
| 針葉樹合板 | 12mm / 24mm | 構造・家具 |
| ラワン合板 | 5.5mm / 12mm / 24mm | 仕上げ・家具 |
| MDF | 12mm / 18mm | 家具・モックアップ |
| 無垢材（杉・檜） | 30mm〜 | 構造・仕上げ |

### ジョイント設計基準
| ジョイント種別 | クリアランス | 用途 |
|---|---|---|
| タイト嵌合 | +0.0〜+0.1mm | 接着固定する箇所 |
| プレス嵌合 | +0.1〜+0.3mm | 叩いて組み立てる箇所 |
| スライド嵌合 | +0.3〜+0.5mm | 着脱可能にする箇所 |
| ルーズ嵌合 | +0.5〜+1.0mm | 調整代を持たせる箇所 |

※ クリアランスは材料・湿度条件により調整が必要

## 5. NG例・よくあるミス

| ミス | 影響 | 正しい対応 |
|---|---|---|
| ビット径を考慮しない隅部設計 | 内角が加工できない | 隅部にドッグボーン（R加工）を設定 |
| クリアランスなしのジョイント | 組立不可 | 用途に応じたクリアランスを設定 |
| レイヤー未整理でCNCデータ出力 | 加工ラインの誤認 | CNC専用レイヤーに分離 |
| ネスティング未確認で設計完了 | 材料不足・コスト超過 | 設計段階でネスティング効率を確認 |
| 版数管理をしない | 旧版で加工してしまう | ファイル名に版数を必ず付与 |
| 組立順序を考慮しない設計 | 物理的に組み立てられない | 組立シミュレーションを実施 |
