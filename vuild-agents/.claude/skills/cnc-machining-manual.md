# CNC加工マニュアル

## このスキルの目的

VUILDのCNC加工業務における作業手順・加工条件・安全基準・品質管理を定めたマニュアル。
製造・加工部のエージェント、および設計部の製作図作成時に参照する。

## 3. 加工準備手順

### Step 1: データ確認
1. 設計データ（DXF/3DM）を受領
2. レイヤー構成の確認（切断線/彫刻線/ドリル穴が分離されているか）
3. 寸法の確認（原寸チェック）
4. ビット径に対する最小内角Rの確認（ビット径の半径以上か）
5. 設計部への質疑事項があれば連絡

### Step 2: CAM設定
1. CAMソフトに設計データをインポート
2. 加工原点の設定（材料の左下角が標準）
3. ツールパスの生成
   - **外形切り抜き**: アウトサイドカット（外側オフセット）
   - **穴・ポケット**: インサイドカット（内側オフセット）
   - **溝**: オンザラインカット
4. タブ（保持部）の設定（切り抜き時、部材の飛び出し防止）
   - タブ幅: 5〜10mm
   - タブ高さ: 2〜3mm
   - タブ間隔: 200〜400mm
5. 加工条件の設定（上記テーブル参照）
6. シミュレーションによる衝突チェック

### Step 3: 材料準備
1. 材料の寸法・状態確認（反り・傷・含水率）
2. 加工機テーブルへの固定（バキューム or クランプ）
3. 材料の平面出し（必要に応じてサーフェシング）
4. 加工原点の設定（X,Y: 材料角、Z: 材料上面）

### Step 4: 加工実行
1. ビットの装着・突出量の確認
2. テストカット（端材で加工条件を確認）
3. 本加工の開始
4. 加工中の監視（異音・振動・煙の確認）
5. 加工完了後のビット状態確認

### Step 5: 後処理
1. タブの除去（ノミ or サンダー）
2. バリ取り・サンディング
3. 部材番号の記入
4. 寸法検査（主要寸法をノギスで確認）
5. 加工記録の記入

## 4. ネスティング（材料取り）ルール

### 基本原則
- 歩留まり率 **80%以上** を目標
- 部材間の間隔: **ビット径 + 2mm** 以上
- 材料端からの距離: **20mm** 以上
- 木目方向の考慮（構造材は木目方向を指定）

### ネスティング最適化の手順
1. 大きな部材から配置
2. 同じ厚さの部材をグループ化
3. 端材エリアにテストカット用スペースを確保
4. 残材の再利用を考慮した配置

## 5. 安全基準

### 加工前チェック
- [ ] 保護メガネの着用
- [ ] 集塵機の起動確認
- [ ] 緊急停止ボタンの位置確認
- [ ] ビットの固定状態確認
- [ ] 材料の固定状態確認
- [ ] 加工範囲内に障害物がないか確認

### 加工中の禁止事項
- 加工中に手を加工範囲内に入れない
- 加工中にビットの交換をしない
- 異音・異臭・振動がある場合は即座に停止
- 無人での加工は禁止（常時監視）

### 緊急時対応
1. **緊急停止**: 赤いボタンを即座に押す
2. **報告**: 責任者（Engineering LEAD）に報告
3. **記録**: 発生状況・原因・対応を記録
4. **再発防止**: 原因分析と対策を実施してから再開

## 6. 品質管理基準

### 寸法公差
| 部位 | 公差 |
|---|---|
| 外形寸法 | ±0.3mm |
| ジョイント部 | ±0.15mm |
| 穴位置 | ±0.2mm |
| 穴径 | ±0.1mm |
| 溝幅 | ±0.2mm |
| 溝深さ | ±0.3mm |

### 表面品質
| 等級 | 基準 | 用途 |
|---|---|---|
| A（化粧面） | バリなし・傷なし・サンディング仕上げ | 見え掛かり面 |
| B（一般面） | 軽微なバリ可・傷なし | 通常の面 |
| C（隠れ面） | バリ除去済み | 組立後見えない面 |

## 7. NG例・よくあるミス

| ミス | 原因 | 対策 |
|---|---|---|
| 部材が加工中に飛ぶ | タブなし or 固定不十分 | タブ設定＋バキューム確認 |
| 切断面がケバ立つ | ビット摩耗 or 送り速度過大 | ビット交換＋条件見直し |
| 寸法が合わない | 加工原点のずれ | 原点設定を再確認 |
| ビットが折れる | 切込み過大 or 異物衝突 | 条件テーブル遵守＋材料確認 |
| 裏面にバリが出る | 捨て板未使用 | 捨て板（MDF）を下敷きに |
| 加工時間が長すぎる | ツールパス非効率 | CAMの最適化設定を見直し |
