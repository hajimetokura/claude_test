# SNS運用マニュアル

## このスキルの目的

VUILDのInstagram運用における戦略・投稿ルール・コンテンツ制作基準を定めたマニュアル。
広報・コミュニケーション部のエージェントがブランドに沿ったSNS運用を行うための基準書。

---

## 1. Instagram運用戦略

### アカウント方針
- **目的**: VUILDの「建築産業の民主化」というビジョンを視覚的に伝え、共感者を増やす
- **ターゲット**: 建築・デザイン関係者 / ものづくりに興味がある一般層 / 自治体・企業の意思決定者
- **KGI**: ブランド認知度の向上 → 問い合わせ・案件獲得への貢献

### コンテンツピラー（柱）

| ピラー | 比率 | 内容例 |
|---|---|---|
| 建築作品 | 40% | 完成写真、ビフォーアフター、空間の使われ方 |
| 製造プロセス | 25% | CNC加工の様子、材料の質感、組立風景 |
| チーム・文化 | 20% | 働く人々、ワークショップ、イベント |
| 業界知見 | 15% | デジタルファブリケーション解説、建築コラム |

## 3. 投稿制作ガイド

### キャプション作成ルール

#### 構成
```
[フック（1行目）]
[空行]
[本文（2〜4行）]
[空行]
[ハッシュタグ]
```

#### フック（1行目）のパターン
| パターン | 例 |
|---|---|
| 問いかけ | 「木で、ここまでできる。」 |
| 数字 | 「327個のパーツが、ひとつの空間になる。」 |
| プロセスの一場面 | 「データから、かたちへ。」 |
| 感覚的表現 | 「杉の香りが、設計図を超えていく。」 |

#### 本文のルール
- 1文40文字以内
- 本文全体で140文字以内
- 宣伝色を避け、ストーリーで伝える
- 技術説明は噛み砕いて平易に

### ハッシュタグ戦略

#### 3層構成（合計15個以内）
| 層 | 数 | 例 |
|---|---|---|
| ブランド固定 | 3〜4個 | #VUILD #建築の民主化 #デジタルファブリケーション |
| テーマ別 | 5〜7個 | #木造建築 #CNC加工 #パラメトリック設計 #家具デザイン |
| トレンド・一般 | 3〜5個 | #建築 #ものづくり #woodworking #architecture |

## 4. ビジュアル基準

### 写真のトーン
| 項目 | 推奨 | 避ける |
|---|---|---|
| 光 | 自然光、柔らかい | フラッシュ直射、暗すぎ |
| 色調 | 暖色寄り、ナチュラル | 彩度過多、冷色系フィルター |
| 構図 | 余白を活かす、ミニマル | ごちゃごちゃした構図 |
| 被写体 | 人の手、木の質感、加工の瞬間 | ストックフォト感 |
| 加工 | 控えめな調整のみ | 過度なフィルター |

### リール制作基準
| 要素 | 基準 |
|---|---|
| 尺 | 30秒〜60秒 |
| 冒頭3秒 | 最もインパクトのあるシーンを配置 |
| テキスト | 画面の安全エリア内に配置、フォントサイズ大きめ |
| BGM | VUILDのトーンに合うもの（アコースティック/エレクトロニカ系） |
| エンディング | VUILDロゴ or アカウント名 |

## 5. エンゲージメント管理

### コメント返信方針
| コメント種別 | 対応 | 返信例 |
|---|---|---|
| ポジティブ感想 | 24時間以内に返信 | 「ありがとうございます！○○のプロジェクトです」 |
| 技術的な質問 | 確認後48時間以内 | 「こちらのCNC加工では〜を使用しています」 |
| 案件相談 | DMに誘導 | 「ありがとうございます！DMにてご相談承ります」 |
| ネガティブ | ユーザーに確認後対応 | （ケースバイケース） |
| スパム | 削除・ブロック | 返信不要 |

### DM対応
- 案件に繋がりそうなDMは **24時間以内** に初回返信
- 案件相談は営業部（吉田）に連携
- 一般的な質問はテンプレート返信可

## 7. NG例・よくあるミス

| ミス | 影響 | 正しい対応 |
|---|---|---|
| 「フォローしてね！」と書く | ブランド毀損 | ストーリーで自然に伝える |
| 加工前の写真で投稿 | 品質低下 | 必ずトーン調整後に投稿 |
| ハッシュタグ30個使う | スパム認定リスク | 15個以内に厳選 |
| 未許可のクライアントPJ掲載 | 信頼失墜 | 事前に掲載許可を確認 |
| 投稿時間がバラバラ | アルゴリズム不利 | 推奨時間帯に統一 |
| ネガティブコメントを放置 | ブランドリスク | 方針を決めて対応 |
| 他社の写真を無断使用 | 著作権侵害 | 自社撮影 or 許可取得済みのみ |
