# 営業戦略プレイブック

## このスキルの目的

VUILDの営業活動における戦略・手法・テンプレート・判断基準を定めたマニュアル。
事業戦略・営業部のエージェントが統一されたアプローチで営業を推進するための基準書。

---

## 1. VUILDの営業ポジショニング

### ターゲット顧客セグメント

| セグメント | 具体例 | ニーズ | VUILDの提供価値 |
|---|---|---|---|
| 設計事務所 | 建築家・デザイナー | 複雑な形状の実現 | パラメトリック設計〜CNC加工の一気通貫 |
| ゼネコン・工務店 | 地方工務店〜中堅ゼネコン | コスト削減・工期短縮 | デジタルプレカットによる効率化 |
| 自治体・公共機関 | 市町村・教育委員会 | 地域資源の活用 | 地域材×デジタル加工 |
| 企業（オフィス・店舗） | 小売・飲食・IT企業 | 独自性のある空間 | カスタムデザイン家具・空間 |
| 教育機関 | 大学・専門学校 | 実践的な教育環境 | ShopBot導入・ワークショップ |

### 差別化ポイント（USP）
1. **設計から加工まで一気通貫** - 設計データが直接CNC加工データになる
2. **パラメトリック設計** - 数値を変えるだけでカスタマイズ可能
3. **地域材の活用** - 日本各地の木材を活用した製造
4. **建築産業の民主化** - 専門知識がなくてもものづくりに参加できる
5. **EMARF** - クラウドプレカットサービスによるアクセシビリティ

## 2. 営業プロセス（パイプライン）

```
① リード獲得 → ② 初回接触 → ③ ヒアリング → ④ 提案 → ⑤ 見積 → ⑥ 交渉 → ⑦ 受注
```

### 各ステージの定義と行動

| ステージ | 定義 | やること | 成果物 |
|---|---|---|---|
| ① リード | 潜在顧客の発見 | SNS反応・問い合わせ・紹介の把握 | リード情報記録 |
| ② 初回接触 | 最初のコミュニケーション | メール/電話で挨拶、会社紹介 | 初回接触記録 |
| ③ ヒアリング | 課題・要望の把握 | 面談・オンラインMTGで深堀り | ヒアリングシート |
| ④ 提案 | 解決策の提示 | 提案書の作成・プレゼン | 提案書 |
| ⑤ 見積 | 費用の提示 | 見積書の作成・提出 | 見積書 |
| ⑥ 交渉 | 条件の調整 | スコープ・費用・スケジュールの調整 | 合意書ドラフト |
| ⑦ 受注 | 契約締結 | 契約書の締結・キックオフ準備 | 契約書 |

## 4. 提案書構成テンプレート

### 標準構成（10〜15ページ）

1. **表紙**（VUILDロゴ + PJ名 + クライアント名 + 日付）
2. **エグゼクティブサマリー**（1ページ、3行で要約）
3. **課題の理解**（クライアントの課題を言語化）
4. **提案内容**（VUILDの解決策・アプローチ）
5. **設計コンセプト**（ビジュアル重視）
6. **技術・製造アプローチ**（デジタルファブリケーションの優位性）
7. **実績紹介**（類似PJの事例2〜3件）
8. **プロジェクト体制**
9. **スケジュール**
10. **概算費用**
11. **次のステップ**

### 提案書の鉄則
- **顧客視点**: 「VUILDができること」ではなく「あなたの課題をこう解決します」
- **ビジュアル先行**: テキストだけのページを作らない
- **具体性**: 抽象的な表現を避け、事例・数値・写真で語る
- **差別化**: なぜVUILDなのかを明確に

## 5. 見積書作成基準

### 費用項目

| 大項目 | 中項目 | 算出方法 |
|---|---|---|
| 設計費 | コンセプト設計 | 日数 × 日単価 |
|  | 基本設計 | 日数 × 日単価 |
|  | 実施設計 | 日数 × 日単価 |
|  | 製作図 | 日数 × 日単価 |
| 製造費 | 材料費 | 材料量 × 単価 |
|  | 加工費 | 加工時間 × 時間単価 |
|  | 仕上げ費 | 工数 × 日単価 |
| 施工費 | 搬入費 | 距離・量で算出 |
|  | 施工費 | 日数 × 人工 × 日単価 |
| その他 | 諸経費 | （設計+製造+施工）× 10% |
|  | 消費税 | 税抜合計 × 10% |

### 見積のルール
- 見積有効期限: 発行日から **30日間**
- 概算段階: **±30%** の幅を明記
- 詳細見積: **±10%** の精度を確保
- 値引き: Engineering LEADの承認が必要（10%以上の値引きは必須）

## 7. NG例・よくあるミス

| ミス | 影響 | 正しい対応 |
|---|---|---|
| ヒアリングせずに提案 | 的外れな提案 | 必ずヒアリングを実施してから提案 |
| 口頭で金額を伝える | 後で「言った言わない」に | 金額は必ず書面で提示 |
| 実現不可能な納期で受注 | PJ破綻 | 製造部に確認してから納期を提示 |
| 値引きで対応 | 利益率低下 | スコープ調整で対応を検討 |
| 類似実績なしで提案 | 信頼性低下 | 類似技術の実績や、小さいPoCから提案 |
| フォローアップの放置 | 案件ロスト | 提案後1週間以内に必ずフォロー |
