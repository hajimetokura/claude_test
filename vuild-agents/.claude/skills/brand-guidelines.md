# ブランドガイドライン

## このスキルの目的

VUILDのブランドアイデンティティを全エージェントが統一的に理解し、すべてのコミュニケーションでブランドの一貫性を保つためのマニュアル。
**全エージェント必読**。

---

## 1. VUILDのブランドアイデンティティ

### ミッション
**建築産業の民主化**

### ビジョン
テクノロジーの力で、「つくる」をすべての人にひらく。
誰もが自分の暮らす場所を自分で設計し、地域の素材で、地域の技術で形にできる世界。

### バリュー
1. **ひらく** - 閉じた専門知をテクノロジーで民主化する
2. **つくる** - 手を動かし、実際に形にすることを大切にする
3. **つなぐ** - デジタルとフィジカル、都市と地域、設計者と施工者をつなぐ
4. **育てる** - 人材も技術も地域も、長期的な視点で育てる

## 2. トーン & ボイス

### 基本方針
| 項目 | 指針 |
|---|---|
| 全体トーン | プロフェッショナルかつ親しみやすい |
| 技術の話し方 | 正確だが、噛み砕いて伝える |
| 感情表現 | 押し付けがましくなく、共感を生む |
| 未来の語り方 | 地に足のついた希望（空想ではなく） |

### OK表現 / NG表現

| 場面 | OK | NG |
|---|---|---|
| VUILDの紹介 | 「建築をもっと身近にひらく」 | 「建築業界を革命する」 |
| 技術力のアピール | 「デジタルとものづくりの融合」 | 「世界最先端のテクノロジー」 |
| 顧客への提案 | 「一緒につくりましょう」 | 「お任せください」 |
| 業界への言及 | 「もっとよくできる可能性がある」 | 「建築業界は遅れている」 |
| 難易度の表現 | 「テクノロジーでひらく」 | 「誰でも簡単にできる」 |

### 一人称・二人称
- **社外文書の一人称**: 「VUILD」「私たち」
- **使わない一人称**: 「弊社」（堅すぎる）、「自分」（カジュアルすぎる）
- **顧客への呼称**: 「○○様」「皆さま」（「お客様」も可）

## 3. ビジュアルアイデンティティ

### カラーパレット
| 用途 | 色 | 備考 |
|---|---|---|
| メインカラー | 黒 (#1A1A1A) | テキスト・見出し |
| サブカラー | 白 (#FFFFFF) | 背景・余白 |
| アクセント | ウォームベージュ (#C4A882) | 木の温かみを表現 |
| リンク・CTA | ダークグリーン (#2D5016) | 自然・持続可能性 |
| 警告・注意 | テラコッタ (#C75B39) | 赤ではなく土の色 |

### ロゴ使用ルール
- 最小サイズ: 横幅20mm以上
- 周囲の余白: ロゴ高さの50%以上を確保
- 背景色: 白または黒のみ（写真の上に載せない）
- 変形・回転・色変更は禁止

### フォント指針
| 用途 | フォント種 |
|---|---|
| 見出し | ゴシック体（太め）|
| 本文 | ゴシック体（標準）|
| アクセント | 明朝体（見出しの副題のみ）|
| 数字・データ | 等幅ゴシック |

### 写真のトーン
- **推奨**: 自然光、木の質感が伝わる、人の手が映っている、作業の瞬間
- **避ける**: 過度なフィルター加工、ストックフォト感、人物のない無機質な写真

## 4. コミュニケーション別ルール

### Instagram投稿
- キャプションは140文字以内（本文）
- ハッシュタグは最大15個
- 絵文字は控えめに（1投稿3個まで）
- 宣伝色の強いCTAは避ける

### 提案書・見積書
- 表紙にVUILDロゴを配置
- フォント・色はブランドカラーに統一
- ページ番号・日付・機密レベルを記載
- クライアント名をヘッダーに表示

### メール
- 件名: 【VUILD】+ 内容（30文字以内）
- 署名: 会社名・氏名・連絡先を統一フォーマットで
- 本文: 3段落以内、CTA（求めるアクション）を明示

### 議事録・報告書
- VUILDテンプレートを使用
- 日付・出席者・決定事項を冒頭に
- 次のアクション（担当・期限）を末尾に

## 5. 禁止事項チェックリスト

すべての社外発信前に以下を確認:

- [ ] 根拠のない誇張表現がないか（最先端・革命的・世界初）
- [ ] 他社を名指しで批判していないか
- [ ] 未公開プロジェクト情報が含まれていないか
- [ ] クライアントの許可なく名前・写真を使っていないか
- [ ] 機密情報（財務・内部方針）が含まれていないか
- [ ] 建築業界へのネガティブ発言がないか
- [ ] VUILDロゴの使用ルールに違反していないか
- [ ] 誤字・脱字がないか

## 6. よくあるミス

| ミス | 正しい対応 |
|---|---|
| 「弊社」を使う | 「VUILD」「私たち」を使う |
| 「最先端技術で」と書く | 「デジタルファブリケーション技術で」と具体的に |
| 業界を見下す表現 | 「もっとよくできる」とポジティブに |
| ロゴを写真の上に配置 | 白or黒の背景上のみ |
| ストックフォトを使う | 実際のプロジェクト写真を使う |
